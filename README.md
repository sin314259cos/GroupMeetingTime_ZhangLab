# ZhangLab 组会时间台

这是 ZhangLab 的组会时间记录工具。所有历史数据仍保存在 `meeting_times.db` 中，新界面不会改变原有表结构。

## 新界面能做什么

- 三步现场计时：**开始报告 → 进入提问 → 结束并保存**
- 从历史汇报人中直接选择，也可以输入新名字
- 自动填写当天日期和当前时间
- 一键把上一位的结束时间作为下一位的开始时间
- 手动补录和修改已有记录
- 按汇报人、起止日期搜索历史记录
- 查看平均报告、提问和总时长排名
- 导出当前记录为 CSV，或安全备份整个数据库
- 支持跨午夜的时间计算

## 使用方法

### Windows 双击启动

双击 `start_app.bat`。电脑需要安装 Python 3；界面只使用 Python 自带组件，不需要另外安装依赖。

### 命令行启动

```bash
python app.py
```

程序会始终读取与 `app.py` 位于同一文件夹的 `meeting_times.db`，因此从其他目录启动也不会误建数据库。

## 推荐的现场登记流程

1. 选择汇报人，确认日期。
2. 点击“开始报告”。
3. 报告结束时点击“报告结束 · 进入提问”。
4. 提问结束时点击“提问结束 · 保存记录”。
5. 下一位开始前，可点击“接上位结束”快速填入开始时间。

如果是会后补录，直接在右侧填写日期与三个时间，然后点击“保存记录”即可。没有提问环节时，“提问结束”可以留空。

## 数据字段说明

| 字段 | 含义 |
|---|---|
| `start_time` | 报告开始时间 |
| `end_time` | 报告结束、提问开始时间 |
| `question_time` | 提问结束时间 |
| `duration` | 自动计算的报告时长 |
| `question_duration` | 自动计算的提问时长 |

## 旧脚本

原有的 `add.py`、`delete.py`、`average.py` 和 `average_durations.py` 均保留，方便核对历史流程。日常登记建议统一使用 `app.py`。
